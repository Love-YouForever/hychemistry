## 五、评测方法说明

- 用例对齐六个化学工具的能力边界，每类 2–5 题，覆盖正常路径与边界情况
- 工具准确率按「期望工具是否出现在实际 tool_calls 中」判定
- 答案准确率按「回答是否包含预期数值或关键结论」判定，接受同义表述
- 安全拦截用例在调用模型前即被拦截，因此耗时为 0，单独统计召回率
- 模型温度 0.4，单次评测存在小幅波动，结论以多次运行的稳定区间为准

## 六、实验助手（Lab Agent）验证

实验助手不是「再放一个聊天框」：它的安全结论由确定性代码给出，因此不纳入上述 25 题的模型效果评测，而以**规则用例 + 接口实测**验证（[`tests/test_lab_agent.py`](../tests/test_lab_agent.py)，13 例）。

| 验证项 | 方法 | 结果 |
|---|---|---|
| 实验白名单加载 | 单元测试 | 8 个教材实验全部解析成功，配置含阈值 / 禁用试剂 / 异常条件 / 应急处置 |
| 未知实验拦截 | 单元测试 | decision=`block`，返回拒绝话术，**未请求模型** |
| 禁用试剂拦截 | 单元测试 | 命中该实验 forbidden 列表即 `block`（如氯离子检验中外加盐酸造成假阳性） |
| 异常现象 | 单元测试 + 接口实测 | 仅升级为 `warning`，回答开头补【安全警告】，不阻断生成 |
| 检索范围隔离 | 单元测试 | 只召回当前实验片段；无命中时回退该实验概览片段（score 0.0） |
| SSE 首帧 | 单元测试 + 接口实测 | 第一个事件固定为 `safety`，前端可先渲染安全状态再收正文 |
| 降级 | 单元测试 | 模型不可用 → `done{ok:false, mode:"degraded"}`，连接正常关闭 |
| 前缀去重 | 单元测试 | 模型自带【安全警告】时不重复补写 |
| 真实对话 | 浏览器实测 | 选「氯离子检验」+ 异常现象「蒸馏水空白也出现白色沉淀」→ 黄色安全提醒卡 + 【安全警告】+ Top-3 教材来源，仅一条警告前缀 |

结论：实验助手的安全能力可以完全脱离模型被验证——这正是把「是否允许」写进代码而不是写进提示词的价值。
