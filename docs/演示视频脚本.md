## 旁白全文（可直接照读，约 1670 字）

> 这是一个把化学搬进浏览器的项目——元素幻语。它让没有实验室的学校，也能完成一次完整的化学实验。
>
> 中学化学有三重困境：实验条件不足、微观概念抽象、危险实验不敢做。元素幻语用三个方向回应：3D 可视化让微观可见，虚拟实验室让危险可控，AI 助教让问题随时有人回答。
>
> 118 个元素以三维形式排布，可以自由旋转、缩放。点击任意元素，能看到原子序数、相对原子质量、发现者，以及一篇完整的元素图鉴——这些文本后来还成了 AI 助教的知识库。
>
> 这是全项目最有意思的部分。不碰鼠标、不碰屏幕，直接用手——张开手掌旋转，捏合缩放。所有识别都在浏览器本地完成，视频不会上传，既保护隐私，也意味着课堂上老师站在大屏前就能演示。
>
> 实验室按真实科研标准搭建：试剂存储区、实验操作区、仪器分析区、清洁处置区，共 72 项配置，每项都标注规格和使用规范。注意——规范不是写在文档里的死条文。把装着试剂的容器拖进废液缸，系统会自动判定它属于酸性、碱性还是含重金属，给出对应的处置要求。拖精密仪器则会被拦下：固定安装，请到仪器前操作。安全，是被设计进流程里的。
>
> 它不是简单地把问题丢给大模型。模型会先判断需要哪个工具，调用本地的配平算法算出确定结果，再基于结果组织语言。所以答案可验证——这是"AI 可能记错"和"算法一定算对"的区别。
>
> 查元素、算摩尔质量、检索反应现象、查危化品安全，背后是六个可调用的化学工具。
>
> 拍一张手写方程式也能看懂。但重点不只是识别——识别出来之后，配平工具会独立算一遍。两个系统互相检查，避免"看错还讲错"。
>
> 如果问到危险内容，它会在调用模型之前就拦下来，不消耗任何 API 调用，并引导到安全的实验方向。化学是高风险主题，这条线必须画清楚。
>
> 答案从哪来，也写在脸上——每条知识都会附上出处，点开可以看到命中方式和原文片段；查不到就明说是系统建议，不假装有依据。如果模型或网络真的出问题，它会说实话，并给你一个重新试一次的按钮。异常处理不是藏起来的兜底代码，而是用户可以看见的界面。
>
> 同一个页面，叙事逻辑换一下，价值就不一样。首屏多了一个 AI 模式入口——它不问你想看什么，而是问你想解决什么问题。比如"帮我找三个常温下是液态的元素"，它会先去知识库检索，再组织答案，并把出处列在下面。
>
> 周期表不再只是展品。点任意一个元素，侧栏直接开始对话；也可以反过来——先说出你的问题，比如"找稀有气体"，它驱动 3D 周期表把命中的元素高亮出来，再逐条解释。陈列变成了检索，看变成了问。
>
> 传记页也可以被激活。选择一位化学家，他会用第一人称和你谈科研历程、方法论，甚至评价今天的化学发现。请求里带一个 role 字段，后端为这一轮追加角色提示词——同一个 Agent，换一种人格，讲的是同一套可信的知识。
>
> 还有一个更贴近课堂的场景：把一段课文或科普文章贴进来，AI 只根据这段文字回答，逐句标出来自第几段；文里没写的，它会直接说资料未提及。检索、切块、打分都在前端完成，不需要额外服务。
>
> 赛项指南说，界面不要求多炫酷，而是要求稳。所以 WebGL 不可用时不会白屏，会降级成一张能点的 2D 周期表；弱网和移动端不加载首屏视频。炫的部分尽量炫，稳的部分必须稳。
>
> 技术上是四层架构：表现层用 Vue 3 管理主页外壳、AI 面板与对话状态，Three.js 负责 3D 渲染，零构建链、可直接部署；交互层做手势与拖拽；服务层用 Flask 拆成静态托管和 API 两个服务，代理层对流式响应逐块透传；模型层接 DeepSeek 做语义、Qwen3-VL 做视觉、CosyVoice 做语音。前端做过一次模块化重构，把近两万行内联 HTML 拆成三百行结构与二十二个独立模块。
>
> 元素幻语想回答一个问题：大模型已经足够强大，教育产品该把它放在什么位置？我们的答案是——放在学生提问的那一刻，放在需要被验证的答案旁，放在危险话题之前。谢谢观看。

### 常见问题

- **手势识别不灵敏**：提高环境光、让手掌正对摄像头、不要离太近
- **AI 首次回答慢**：录制前先问一次预热，让连接建立
- **流式输出太快看不清**：剪辑时对该片段做 0.5× 慢放，或加"正在调用工具"的特写定格
- **录制时有浏览器地址栏**：按 F11 全屏，或 OBS 裁掉顶部区域
