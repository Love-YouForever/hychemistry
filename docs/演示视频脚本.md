# 《元素幻语》演示视频脚本（当前功能全量版）

> **规格要求**：7 分 30 秒 – 8 分 00 秒 · 1920×1080（1080p）· MP4（H.264）
> **建议时长**：7 分 50 秒
> **旁白字数**：约 1780 字（按每分钟 225 字计算，留出停顿与操作时间）
> **录制方式**：OBS / Windows 自带录屏（Win + G），录制浏览器窗口 + 麦克风旁白
> **分辨率设置**：浏览器全屏（F11）后录制，或 OBS 输出缩放到 1920×1080

---

## 录制前准备清单

- [ ] 启动服务：`.\.venv\Scripts\python.exe server\start_bs.py`
- [ ] 浏览器打开 `https://127.0.0.1:4100`（首次需信任自签证书）
- [ ] 预热一次 AI 对话（主页输入"配平 Fe + O2 = Fe2O3"），避免首次调用延迟
- [ ] 预热一次实验室助手（进实验室 → 打开实验助手 → 随便问一句），确保模型连接已建立
- [ ] 准备一张手写化学方程式照片（如 `Fe + O2 = Fe2O3`）存到桌面
- [ ] 准备一段 200 字左右的化学科普文本，复制到剪贴板，用于「文档问答」
- [ ] 准备 WebGL 降级演示：用 `msedge.exe --disable-webgl` 另开窗口，提前打开周期表页
- [ ] 准备"网络异常"演示：录制时临时停掉后端（`Ctrl+C`）再提问，随后恢复
- [ ] 关闭无关窗口与通知，浏览器隐藏书签栏
- [ ] 麦克风测试，语速控制在每分钟 220–230 字

## 旁白全文（可直接照读，约 1780 字）

> 当门捷列夫在梦里看见元素排成一张表，当居里夫人凝视那抹幽蓝的镭光——化学一直承载着人类对未知世界的好奇。可今天的课堂，面对抽象电子轨道，还有那句"这个实验我们做不了"，学生还能感受到那份悸动吗？今天，我们带来一个答案——元素幻语。
>
> 各位评委老师好，我们是元素幻语团队，一个面向中学化学的沉浸式 AI 交互学习平台。中学化学有三重困境：实验条件不足、微观概念抽象、危险实验不敢做。我们用三条路径回应：3D 可视化让微观可见，虚拟实验室让危险可控，AI 助教让问题随时有人回答。
>
> 118 个元素以三维形式排布，可以自由旋转、缩放。点任意元素，原子序数、相对原子质量、发现者，还有一篇完整的元素图鉴——这些文本后来成了 AI 助教的知识库。周期表不只是展品：点元素，侧栏直接对话；也可以反过来，先问"找出稀有气体"，助教会通过场景动作工具把命中的元素高亮出来，每个结论都能展开看到来源和命中方式。陈列变成了检索，看变成了问。
>
> 这是全项目最好玩的部分。不碰鼠标、不碰屏幕，直接用手——张开手掌旋转，捏合缩放。所有识别都在浏览器本地完成，画面不会上传，既保护隐私，也意味着课堂上老师站在大屏前就能演示。
>
> 实验室按真实科研标准搭建：四大分区、72 项配置，每项都标注规格和使用规范。规范不是死条文：把容器拖进废液缸，系统会判定酸性、碱性还是含重金属，给出对应处置；拖精密仪器会被拦下。更关键的是，这一版我们给它接了一位实验助手。选择教材实验，比如氯离子检验，它就带着这个实验的浓度、温度上限、禁用试剂、异常条件和应急处置来回答。我在"异常现象"里写：蒸馏水空白也出现白色沉淀，再问现在该怎么办——它先亮安全警告，再给出停手、重配试剂、用空白对照排除干扰的步骤，并把依据的教材片段标出来。这里有一道关键设计：安全审查是确定性的代码，不是交给大模型去判断。白名单之外的实验、禁用试剂，在调用模型之前就被拦下；异常现象只会升级成警告，不会被模型"自由发挥"成事故。AI 负责讲解，规则负责守住底线。
>
> 它不是把问题直接丢给大模型。它会在最多四轮里判断该用哪个工具：配平、查元素、算摩尔质量、检索反应现象、查危化品安全、检索知识库、控制场景，一共七个，全部本地确定性计算，答案可验证。知识检索是混合检索：关键词、语义向量、概念扩展、关系证据图一起召回，再用 RRF 融合。所以问"自然界最硬的物质"，它能沿"金刚石—碳—同素异形体"这条两跳关系找到原文依据，并把来源片段列出来。
>
> 拍一张手写方程式也能看懂。识别之后，配平工具会再独立算一遍，两个系统互相检查；识别不确定时自动降级到本地 OCR，不会卡死。
>
> 回答是口语化的，可以直接朗读，逐句预取，随时能打断。它还准备了随堂小测：基于刚才的对话自动出题、自动判分、逐题解析。
>
> 问到危险内容，它在调用模型之前就拦下来，不消耗任何接口调用。模型回答里的数值还会和工具结果自动比对，对不上就纠正——不让它自信地说错。这些都在运行指标看板里实时可见。
>

>
> 技术上是四层：表现层 Vue 3 与 Three.js，服务层 Flask 拆成静态托管和 API 两个服务，模型层文本用 DeepSeek、视觉用 Qwen3-VL、语音用 CosyVoice，数据层是元素图鉴和教材实验知识库，全部 Docker 化部署，手机横屏可用。它也很轻：一所学校一台普通服务器就能部署，B 端可以按校采购，公益版面向没有实验室的乡村学校免费开放。元素幻语想回答一个问题：大模型足够强大之后，教育产品该把它放在什么位置？我们的答案是——放在学生提问的那一刻，放在需要被验证的答案旁边，放在危险发生之前。让化学更可见、更安全、也更好玩。元素幻语，谢谢各位评委。

## 剪辑与输出

| 项目 | 建议 |
|---|---|
| 剪辑软件 | 剪映专业版 / DaVinci Resolve（免费） |
| 分辨率 | 1920×1080，帧率 30fps |
| 码率 | 8–12 Mbps（H.264） |
| 音频 | 降噪 + 音量标准化到 -16 LUFS，背景音乐压到 -28 dB |
| 字幕 | 关键术语加字幕（Agent、RAG、RRF、Function Calling、Prompt Injection、降级） |
| 转场 | 段间 0.3s 淡入淡出或硬切，避免花哨特效 |
| 导出 | MP4 / H.264 / AAC，文件名：`元素幻语_演示视频.mp4` |

### 常见问题

- **实验室助手首次响应慢**：录制前先问一次预热，确保模型连接已建立
- **安全提醒卡片一闪而过**：剪辑时对该段做 0.5× 慢放并加圈注
- **手势识别不灵敏**：提高环境光、手掌正对摄像头、别离太近
- **流式输出太快看不清**：剪辑时慢放，或加"正在调用工具"特写定格
- **录制时有浏览器地址栏**：F11 全屏，或 OBS 裁掉顶部区域
- **实验室移动端演示**：需横屏，先用 DevTools 设备模拟并旋转视角再录
