## 六、实现与降级边界

- `load_chunks` 按每个元素接受句子的顺序生成稳定 `元素名#序号` ID，短句过滤不会改变其他元素的编号。
- 关系图只接受 `element/form/property` 节点及 `allotrope_of/form_of/has_property/related_to` 边；每条边必须有真实证据块，且文本支持非元素端点、块来源支持元素端点。
- 查询使用全局最长、非重叠别名匹配，只接受最多两跳、终止于有效元素且证据完整的路径，并限制返回路径数。查询明确指定某同素异形体时，禁止借另一相似同素异形体搭桥。
- 关系证据是 RRF 第四路候选，重排层级为“关系证据 > 显式元素 > 概念扩展 > 普通召回”；原三路、概念扩展和同元素最多两条规则均保留。
- 图文件缺失、JSON 无效、证据 ID 不存在或文本不匹配时关系路为空，自动回退原混合检索。普通结果仍只有“来源/内容/匹配度/命中方式”，关系命中额外返回 `path_id/relation_path/evidence_ids`。
- 本方案不做开放世界推理，也不判断命题真假；它只返回有语料证据的受控关系，未覆盖问题仍由原检索或大模型处理。
