# 中学低危基础化学实验知识库

## EXP-SALT-SAND-SEPARATION｜食盐与泥沙的分离（溶解、过滤与蒸发）

**experiment_id:** `exp-salt-sand-separation`  
**实验类别:** 基础操作；物质分离  
**适用学段:** 初中/高中  
**关键词:** 溶解、过滤、蒸发、结晶、氯化钠、泥沙

### 实验原理

氯化钠易溶于水，砂在水中难溶。加水搅拌使氯化钠进入溶液，过滤可截留砂粒；将滤液温和蒸发并冷却，可析出氯化钠晶体。该流程不能去除可能存在的可溶性杂质。

### 标准步骤

1. 取约1 g食盐与洁净砂的混合物，加入约15 mL水，搅拌至食盐溶解。
2. 用湿润的滤纸过滤混合物，并用少量水洗涤滤纸上的砂，将洗液并入滤液。
3. 将滤液转入蒸发皿，用水浴或有温控的电热设备温和加热。
4. 滤液浓缩并出现晶膜后停止加热，冷却观察晶体；不要将蒸发皿加热至干。

### 预期现象

砂留在滤纸上，滤液澄清；滤液浓缩、冷却后可观察到白色氯化钠晶体。

### 安全注意事项

1. 白名单上限：食盐水≤10%（质量分数），每组食盐与砂的混合物≤2 g；样液≤80 ℃。禁止明火和干烧。
2. 佩戴护目镜；取放热器皿时使用坩埚钳或隔热垫，不直接触摸热玻璃。
3. 发生飞溅、干烧、玻璃破损或电热设备异常时，立即停止加热并通知教师；热液或热器皿接触皮肤时用流动凉水持续冲洗至少20分钟。碎玻璃勿徒手清理。

### 常见错误与误差分析

- 食盐未充分溶解就过滤，会使部分氯化钠留在滤纸或砂中，降低回收率。
- 滤纸破损或液体沿滤纸边缘流过，会使砂进入滤液，影响分离效果。
- 将蒸发皿加热至干可能造成飞溅、物料损失或器皿过热。

## EXP-NACL-SOLUTION-PREPARATION｜一定物质的量浓度的氯化钠溶液配制

**experiment_id:** `exp-nacl-solution-preparation`  
**实验类别:** 基础操作；定量配制  
**适用学段:** 高中  
**关键词:** 物质的量浓度、称量、容量瓶、定容、氯化钠

### 实验原理

物质的量浓度由溶质的物质的量与溶液体积之比确定，即 $c=n/V$。配制100.0 mL、0.100 mol/L的氯化钠溶液，理论上需约0.584 g氯化钠。准确称量、定量转移、洗涤和定容是控制浓度的关键。

### 标准步骤

1. 计算所需氯化钠质量，称取约0.584 g氯化钠；称量精度应与所用天平相符。
2. 将氯化钠放入烧杯，加入约40–50 mL水，搅拌至完全溶解；配液过程中不加热。
3. 将溶液转入100 mL容量瓶，用少量水洗涤烧杯和玻璃棒2–3次，洗液一并转入容量瓶。
4. 加水至刻度线附近，再用滴管逐滴加水，使液面凹液面的最低点与刻度线相切；塞紧瓶塞，反复倒转混匀并贴上标签。

### 预期现象

所得溶液无色、澄清、均一，液面达到容量瓶刻度；目标浓度约为0.100 mol/L。

### 安全注意事项

1. 白名单上限：目标浓度0.100 mol/L，配制溶液最高≤0.50 mol/L；室温配制且不加热，容量瓶不得加热。
2. 佩戴护目镜，轻拿轻放玻璃仪器；不得用嘴吸取液体，试剂和配制液均须贴标签。
3. 玻璃器皿破裂或溶液洒漏时停止操作并通知教师；碎玻璃勿徒手清理。溶液进入眼睛时用洗眼器或流动清水持续冲洗至少15分钟。

### 常见错误与误差分析

- 未将烧杯和玻璃棒上的残液洗入容量瓶，会造成溶质损失，使配得溶液浓度偏低。
- 加水超过刻度线会使实际体积偏大，导致溶液浓度偏低；应重新配制，不应直接倒出部分溶液补救。
- 在溶液温度偏高时定容，冷却后体积会收缩，可能导致实际浓度偏高；应将溶液恢复至室温后定容。
- 未完全溶解就定容，会使溶液不均一并影响浓度准确性。

## EXP-CO2-GENERATION-PROPERTIES｜二氧化碳的制取与性质

**experiment_id:** `exp-co2-generation-properties`  
**实验类别:** 气体制取；物质性质  
**适用学段:** 初中/高中  
**关键词:** 二氧化碳、碳酸氢钠、乙酸、石灰水、碳酸钙

### 实验原理

碳酸氢钠与乙酸反应生成乙酸钠、水和二氧化碳：$NaHCO_3+CH_3COOH\rightarrow CH_3COONa+H_2O+CO_2\uparrow$。二氧化碳通入澄清石灰水后生成难溶的碳酸钙，使溶液变浑浊。持续通入过量二氧化碳时，碳酸钙可转化为可溶性碳酸氢钙。

### 标准步骤

1. 在微型发生装置中放入约0.20 g碳酸氢钠，准备约5 mL石灰水作为检验液。
2. 检查导气管通畅，按教师示范连接装置；接收端保持对大气开放，不密闭收集气体。
3. 缓慢加入约5 mL、浓度不高于0.50 mol/L的乙酸溶液，观察产生的气体及石灰水变化。
4. 石灰水变浑浊后停止通气。结束操作时按教师示范使导气管与石灰水脱离，再拆卸装置；不持续鼓泡。

### 预期现象

碳酸氢钠与乙酸反应产生无色气体；气体通入澄清石灰水后，石灰水出现白色浑浊。反应方程式为 $CO_2+Ca(OH)_2\rightarrow CaCO_3\downarrow+H_2O$。

### 安全注意事项

1. 白名单上限：乙酸≤0.50 mol/L，石灰水≤0.02 mol/L，碳酸氢钠≤0.20 g/组；不加热。
2. 佩戴护目镜，缓慢加液；导气管必须保持通畅，禁止堵塞导气管或将气体密闭收集，不用明火检验气体。
3. 不近距离嗅闻气体。发生剧烈起泡、液体冲入导气管、装置鼓胀或出现异常气味时，停止加液并通知教师，不自行拆卸异常装置。
4. 试液溅入眼睛或皮肤时用流动清水持续冲洗至少15分钟；如有呼吸不适，移至空气新鲜处并立即求助。

### 常见错误与误差分析

- 持续通入过量二氧化碳，会生成可溶性碳酸氢钙，浑浊可能减弱甚至消失。
- 装置连接漏气会使通入石灰水的气体减少，现象不明显。
- 导气管堵塞或接收端被封闭会造成压力升高，必须停止操作并通知教师。

## EXP-IRON-COPPER-SULFATE-REACTION｜铁与硫酸铜溶液的反应

**experiment_id:** `exp-iron-copper-sulfate-reaction`  
**实验类别:** 物质性质；置换反应；氧化还原反应  
**适用学段:** 初中/高中  
**关键词:** 铁、铜、硫酸铜、置换反应、氧化还原

### 实验原理

铁的金属活动性强于铜，可将硫酸铜溶液中的铜离子还原为铜单质，自身被氧化为亚铁离子。离子方程式为 $Fe+Cu^{2+}\rightarrow Fe^{2+}+Cu$，体现置换反应和氧化还原反应特征。

### 标准步骤

1. 在试管中加入约5 mL、浓度不高于0.10 mol/L的硫酸铜溶液。
2. 用镊子或夹具将洁净铁片放入溶液中，静置约5–10分钟，不加热。
3. 观察铁片表面和溶液颜色变化；必要时用镊子取出铁片观察表面沉积物。
4. 将铁片、剩余溶液及冲洗液按教师要求收集，记录现象并写出化学方程式。

### 预期现象

铁片表面逐渐出现红棕色铜；蓝色硫酸铜溶液颜色变浅。溶液中亚铁离子较多时可能呈浅绿色。分子方程式为 $Fe+CuSO_4\rightarrow FeSO_4+Cu$。

### 安全注意事项

1. 白名单上限：硫酸铜溶液≤0.10 mol/L，每组溶液≤5 mL；不加热。
2. 佩戴护目镜，使用镊子夹取铁片，避免硫酸铜溶液接触眼睛、皮肤或衣物。
3. 硫酸铜对环境有害，所有含铜废液、沉淀和冲洗液集中回收，不倒入水槽；实验后洗手。
4. 发生洒漏或溅入眼睛、皮肤时停止操作并通知教师，用流动清水持续冲洗至少15分钟。

### 常见错误与误差分析

- 铁片表面锈层或油污未清除，会阻碍铁与铜离子接触，使反应变慢或现象不明显。
- 反应时间过短或溶液浓度偏低，会使铜沉积量少、溶液颜色变化不明显。
- 使用的铁片过小或未浸入溶液，会减少反应接触面积。

## EXP-ACID-BASE-NEUTRALIZATION｜稀盐酸与稀氢氧化钠的中和反应

**experiment_id:** `exp-acid-base-neutralization`  
**实验类别:** 酸碱反应；定性检验  
**适用学段:** 初中/高中  
**关键词:** 盐酸、氢氧化钠、中和反应、pH、氢离子、氢氧根离子

### 实验原理

稀盐酸提供氢离子，稀氢氧化钠提供氢氧根离子，两者发生中和反应，离子方程式为 $H^++OH^-\rightarrow H_2O$，分子方程式为 $HCl+NaOH\rightarrow NaCl+H_2O$。可用pH试纸观察溶液由酸性逐步接近中性。

### 标准步骤

1. 在点滴板或小烧杯中加入约2 mL、0.050 mol/L盐酸；用干净玻璃棒取一滴点在pH试纸上，记录初始酸性。
2. 用滴管逐滴加入同浓度氢氧化钠溶液，每次加液后轻轻混匀。
3. 接近中性时放慢滴加速度，用干净玻璃棒取少量液滴点在新的pH试纸上；pH接近7时停止。
4. 记录滴加体积和pH变化，按教师要求处置溶液；不得将用过的试纸放回试液。

### 预期现象

溶液pH由酸性逐渐接近中性，pH试纸颜色随之变化。微量操作下通常无明显温升，也不应产生气体；试纸读数只能用于判断pH的大致范围。

### 安全注意事项

1. 白名单上限：盐酸和氢氧化钠均≤0.10 mol/L，建议使用0.050 mol/L；每份溶液≤5 mL，不加热。
2. 佩戴护目镜，少量取液；不得用嘴吸取液体，不将pH试纸直接投入试液中。
3. 稀酸、稀碱仍可能刺激眼睛和皮肤。发生洒漏、接触或异常现象时立即停止操作并通知教师；眼睛接触时用洗眼器或流动清水持续冲洗至少15分钟。
4. 泄漏不得自行用其他试剂中和，由教师按校内酸碱泄漏预案处置。

### 常见错误与误差分析

- 氢氧化钠加入过快或混匀不充分，容易越过中性点，使测得pH偏高。
- 将用过的pH试纸放回试液会造成污染，影响后续判断。
- 玻璃棒或滴管未清洗干净会带入其他酸碱，导致pH读数偏差。
- pH试纸读数精度有限，不能替代精密酸碱滴定。

## EXP-CHLORIDE-ION-TEST｜氯离子的检验

**experiment_id:** `exp-chloride-ion-test`  
**实验类别:** 经典定性检验；沉淀反应  
**适用学段:** 初中/高中  
**关键词:** 氯离子、硝酸银、氯化银、白色沉淀、对照实验

### 实验原理

银离子与氯离子结合生成难溶的氯化银白色沉淀，离子方程式为 $Ag^++Cl^-\rightarrow AgCl\downarrow$。复杂样品中的其他离子也可能与银离子形成沉淀，因此该方法宜用于已知或组成简单的样品，并设置空白对照。

### 标准步骤

1. 在点滴板上分别加入约1 mL待测氯化物溶液、约1 mL蒸馏水空白，以及约1 mL已知氯化钠溶液作为阳性对照。
2. 用不同滴管分别向各孔滴加2–3滴、浓度不高于0.05 mol/L的硝酸银溶液。
3. 轻轻振荡点滴板，观察并比较待测液、蒸馏水空白和阳性对照的变化。
4. 记录结果和离子方程式；含银液体、沉淀及清洗液均按教师要求收集。

### 预期现象

含氯离子的样液和氯化钠阳性对照中出现白色沉淀；蒸馏水空白应保持澄清。若样品组成复杂，白色沉淀不能单独作为氯离子存在的充分证据。

### 安全注意事项

1. 白名单上限：硝酸银溶液≤0.05 mol/L，待测氯化物溶液≤0.10 mol/L；每组硝酸银≤1 mL，不加热。
2. 佩戴护目镜，使用教师配制的稀硝酸银溶液；避免试剂接触皮肤、眼睛和衣物。
3. 不用盐酸作为外加检验试剂，避免引入氯离子；使用专用滴管，防止交叉污染。
4. 含银废液和沉淀单独收集，不倒入下水道。硝酸银接触皮肤或眼睛时用流动清水持续冲洗至少15分钟并通知教师。

### 常见错误与误差分析

- 滴管或容器受到含氯试剂污染，会使蒸馏水空白也产生白色沉淀，造成假阳性。
- 用盐酸处理样液会额外引入氯离子，导致检验结果失真。
- 未设置空白或阳性对照会降低判断可靠性。
- 碳酸根、磷酸根等离子也可能与银离子形成沉淀；对复杂未知样品不能仅凭白色沉淀确认氯离子。

## EXP-STARCH-IODINE-TEST｜淀粉的碘检验

**experiment_id:** `exp-starch-iodine-test`  
**实验类别:** 经典定性检验；显色反应  
**适用学段:** 初中/高中  
**关键词:** 淀粉、碘、碘化钾、蓝黑色、食品检验

### 实验原理

碘分子及多碘离子可进入直链淀粉的螺旋结构，形成蓝色至蓝黑色的有色络合物，可用于淀粉的定性检验。碘液本身呈黄褐色；样品自身颜色过深时可能干扰观察。

### 标准步骤

1. 在白色点滴板上分别加入约1 mL淀粉溶液和约1 mL水，作为样品与空白对照。
2. 用滴管分别向两孔滴加1–2滴稀碘-碘化钾水溶液。
3. 用洁净玻璃棒分别轻轻混匀，观察颜色变化。
4. 检验食品样品时，取少量样品置于点滴板上加一滴碘液，并与空白对照比较；按教师要求处置样品和废液。

### 预期现象

淀粉溶液或含淀粉样品变为蓝色至蓝黑色；水空白保持碘液原有的黄褐色。

### 安全注意事项

1. 白名单上限：碘-碘化钾水溶液中I₂≤0.05%（质量分数），淀粉样液≤1%；不加热。
2. 佩戴护目镜，使用少量水溶液；禁止品尝样品或试剂，避免碘液接触皮肤和衣物。
3. 不使用含乙醇的碘酊，不使用浓碘液。发生洒漏或眼部接触时立即通知教师，并用流动清水持续冲洗至少15分钟。
4. 洒漏按含碘试剂流程处理；不得用酒精或其他有机溶剂擦拭皮肤。

### 常见错误与误差分析

- 碘液过稀、样品中淀粉含量很低或滴加量不足，会使蓝黑色不明显。
- 样品自身颜色太深会遮盖显色，宜使用白色背景并设置对照。
- 加热可使蓝黑色暂时减弱，冷却后颜色可能恢复；本实验不要求加热。

## EXP-CALCIUM-CARBONATE-PRECIPITATION｜碳酸钙沉淀的制备（复分解反应）

**experiment_id:** `exp-calcium-carbonate-precipitation`  
**实验类别:** 物质制备；沉淀反应；复分解反应  
**适用学段:** 初中/高中  
**关键词:** 碳酸钙、氯化钙、碳酸钠、沉淀、离子方程式

### 实验原理

氯化钙和碳酸钠在水溶液中电离出的钙离子与碳酸根离子结合，生成难溶的碳酸钙沉淀。离子方程式为 $Ca^{2+}+CO_3^{2-}\rightarrow CaCO_3\downarrow$，分子方程式为 $CaCl_2+Na_2CO_3\rightarrow CaCO_3\downarrow+2NaCl$。

### 标准步骤

1. 在点滴板或小烧杯中加入约2 mL、浓度不高于0.10 mol/L的氯化钙溶液。
2. 用滴管缓慢加入约2 mL、浓度不高于0.10 mol/L的碳酸钠溶液，轻轻振荡混匀。
3. 静置片刻，观察沉淀和上层液体；如需过滤，使用小型过滤装置并在教师指导下进行。
4. 写出反应的分子方程式和离子方程式，按教师要求收集沉淀及剩余液体。

### 预期现象

两种溶液混合后出现白色碳酸钙沉淀；静置后，白色固体逐渐沉降，上层液体基本澄清。

### 安全注意事项

1. 白名单上限：氯化钙和碳酸钠溶液均≤0.10 mol/L，每组总液量≤10 mL；不加热。
2. 佩戴护目镜，使用预先配制的稀溶液；避免试液接触眼睛或皮肤，不得品尝试液。
3. 使用专用滴管，避免不同试剂交叉污染；不使用干燥碳酸钠粉末进行本实验，也不加入酸。
4. 发生飞溅、异常发热、刺激性气味或玻璃破损时停止操作并通知教师；眼睛或皮肤接触试液时用流动清水持续冲洗至少15分钟。

### 常见错误与误差分析

- 滴管或容器受到其他试剂污染，可能在反应前出现浑浊，影响现象判断。
- 溶液浓度过低或试剂标签错误，会使沉淀量少或现象异常。
- 加入酸会消耗碳酸根并改变反应结果；不得自行加入酸处理废液。
- 混合后未静置就观察，可能因沉淀悬浮而难以判断上层液体是否澄清。
