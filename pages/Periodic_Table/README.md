# 小於菟交互式3D元素周期表

这是一个提供化学元素三维模型展示的交互式Web应用。
数据来自 维基百科。
有颜值有实力的化学研究/学习利器。

## 特性
### 描述
- 3D模型展示：每个元素的原子三维模型动态展示。
- 3D周期表：炫酷的3D周期表。
- 元素信息：提供每个元素的基本信息，如原子序数、符号、名称和原子质量、元素历史、应用等
- 状态显示：根据温度显示元素的物态（固态、液态、气态）。
- 多语言支持：可切换语言，中英文支持

## 安装

### 依赖项

确保安装以下依赖：
见 requirements.txt 文件。

### 安装步骤

1. 克隆仓库：
   ```bash
   git clone https://gitee.com/Gitree-XiaoWuTu/WuTu-3D-Periodic-Table-of-Chemical-Elements.git
   ```

2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 爬取数据：
    注意，依赖国际上网！
    ```bash
   python advanced_downloader.py
    ```
4. 启动服务：
   ```bash
   python app.py
   ```

## 使用

访问应用的主页以查看交互式3D元素周期表，点击任一元素以查看其详细信息和3D模型。

## 数据获取

应用通过API从维基百科获取元素数据，并能下载和保存相关图片，下载数据后可国内查询维基信息。
